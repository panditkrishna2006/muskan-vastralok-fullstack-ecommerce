# Muskan Vastralok

Muskan Vastralok is a full-stack e-commerce website developed for a saree and ethnic wear store. The project focuses on creating a simple and user-friendly shopping experience with product browsing, cart management, checkout and order handling.

## About the Project

The main idea behind this project was to build a complete e-commerce website where users can explore products, view product details, add items to their cart and place orders.

The project is divided into two parts:

- Frontend – Website interface and user interactions
- Backend – Server-side logic and API handling

## Features

- Home page with product sections and banners
- Product listing and product details
- Shopping cart
- Checkout page
- Order placement
- Order history
- Admin section
- Responsive design for different screen sizes
- Backend API for handling application data

## Technologies Used

**Frontend**
- HTML
- CSS
- JavaScript

**Backend**
- Node.js

Running the Project-

Backend:
Open the Backend folder in the terminal and install the required packages:
  npm install

Start the server:
  node server.js
  
Frontend:
Open Frontend/index.html in a browser or use VS Code Live Server.
